# Royal Radience

Royal Radience is a single-page website for a luxury beauty studio. It presents bridal makeup, hair styling, skincare, and nail art, with a gallery, client reviews, and an appointment form.

## Tech stack

- React 19
- Vite
- Tailwind CSS 4
- Framer Motion
- Lucide React and React Icons

## Getting started

```bash
npm install
npm run dev
```

Other scripts:

- `npm run build` — production build
- `npm run preview` — preview the production build
- `npm run lint` — run Oxlint

## Project structure

Pages are composed in `src/App.jsx` from these components:

| Component | Role |
| --- | --- |
| `Navbar` | Fixed navigation and Book Now link |
| `Hero` | Opening headline and call to action |
| `About` | Studio introduction |
| `Services` | Bridal makeup, hair, skincare, and nail art |
| `Gallery` | Look and salon photos |
| `Reviews` | Client testimonials |
| `Booking` | Appointment form and phone number |
| `Footer` | Links, services, and studio contact |
| `WhatsAppButton` | Floating WhatsApp chat link |
